## Print layouts

Labels are printed in **batches** from the Dashboard or Print Queue — not one-by-one after each intake registration.

| Layout | Size | Per sheet | Best for |
| --- | --- | --- | --- |
| **Avery 5163** | 2" × 4" | 10 | Default file labels |
| **Avery 94205** | 1.5" × 3.75" clear | 10 | Compact / clear stock |

## Needs label

On the Dashboard **Find & print** filters, use the **Needs label** chip (next to **Active**) to show only students who have **never** appeared in print history.

| Behavior | Detail |
| --- | --- |
| Who appears | Non-archived students with no Label ID / Student ID in any print job for your school |
| Who is hidden | Anyone already logged in print history (including older jobs, not just recent batches) |
| After you print | Confirm **Yes — mark as printed** in the print preview; Needs label refreshes when that succeeds (and when you close preview) |
| Combine filters | Leave **Active** on to see active + never printed, or turn Active off for all statuses |

The amber **Needs label — never printed** banner at the top of Find & print uses the same rule and shows the newest students first, with **View all** to apply the chip filter.

<Tip>
  After **Download Word Doc** or browser Print, confirm that labels printed successfully. Choosing **No** leaves students on **Needs label**. Labels printed outside the app are never logged.
</Tip>

### What appears on each label

| Element | Detail |
| --- | --- |
| **Name** | **Last, First** (comma for filing) |
| **DOB** | Calendar date (`YYYY-MM-DD` on the sheet) |
| **Sequence** | 5-digit batch number (`00001`, `00002`, …) in print order |
| **Barcode** | **Label ID** (e.g. `1990-TP-0000010`) |
| **QR** | Opens the public student page |

The 5-digit sequence is the position in **this print job**, not the 7-digit counter inside the Label ID.

### Recommended print path (Avery)

1. On the Dashboard, click **Needs label** (optional) so you only see students who still need a first print.
2. Select students (or use **Print All**), or open **Daily → Print Queue**.
3. Open the label preview and choose **Avery 5163** or **94205**.
4. Click **Download Word Doc**.
5. Open the file in Microsoft Word and print on **Letter (8.5"×11")** at **100%** scale with **margins None**.
6. Back in the app, confirm **Yes — mark as printed** (or **No** if the sheet failed so they stay on Needs label).

Browser CSS print is not used for Avery sheets.

<Tip>
  Print in multiples of **10** labels to avoid wasting partial sheets.
</Tip>

## Label stock inventory

Admins and Data Leads track Avery inventory under **Print → Label Stock**. Stock decreases when staff confirm labels printed successfully — not on preview alone, and not on Word download alone. See [Label stock](/admin/label-stock).

## Student QR codes

Scanning a student label QR opens a public detail page:

```
https://nycadultedlabels.nyc/student/{labelId}
```

The page shows Label ID, Student ID, name, DOB, cabinet/drawer or archive location, school, and sibling links. No login is required.

## Archive box QR codes

Physical archive box labels include a separate QR that opens:

```
https://nycadultedlabels.nyc/archive/box/{boxId}
```

That public page lists every student file in the box plus storage location. You can also **Download PDF** (page 1 = label + QR, page 2 = two-column student list).

When a **RETURNING** archived student is logged in Intake, staff see this same box location with a QR so they can find paperwork without assigning a new drawer.
