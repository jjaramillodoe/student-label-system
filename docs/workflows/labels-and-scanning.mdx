## Print layouts

Labels are printed in **batches** from the Dashboard or Print Queue — not one-by-one after each intake registration.

| Layout | Size | Per sheet | Best for |
| --- | --- | --- | --- |
| **Avery 5163** | 2" × 4" | 10 | Default file labels |
| **Avery 94205** | 1.5" × 3.75" clear | 10 | Compact / clear stock |

Both layouts include student name, DOB, barcode (**Label ID**), and QR code. You can also download a Word (DOCX) sheet for offline printing.

<Tip>
  Print in multiples of **10** labels to avoid wasting partial sheets.
</Tip>

<Info>
  Intake success no longer opens a single-label print preview. Use **Print** / **Print Queue** after selecting the students you need.
</Info>

## Student QR codes

Scanning a student label QR opens a public detail page:

```
https://student-label-system.vercel.app/student/{labelId}
```

The page shows Label ID, Student ID, name, DOB, cabinet/drawer or archive location, school, and sibling links. No login is required.

## Archive box QR codes

Physical archive box labels include a separate QR that opens:

```
https://student-label-system.vercel.app/archive/box/{boxId}
```

That public page lists every student file in the box plus storage location. You can also **Download PDF** (page 1 = label + QR, page 2 = two-column student list).

When a **RETURNING** archived student is logged in Intake, staff see this same box location with a QR so they can find paperwork without assigning a new drawer.

See [Archive and school year](/storage/archive-and-school-year) and [Intake workflow](/workflows/intake).
