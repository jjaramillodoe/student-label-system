**Students → Enrollment** (`/admin/enrollment`) shows registration activity and intake visit issues.

## Metrics

- Today, This Week, This Month, All Time
- Staff leaderboard with ranking and progress bars
- Daily trend chart

## Table filters

Filter by period, staff member, or student/staff name search. Each row shows who registered the student (name + email).

## Intake issues

Enrollment can flag visits with:

| Flag | Meaning |
| --- | --- |
| **Outside Session Hours** | Time In or Time Out falls outside the school's session window |
| **Early Time Out** | Time Out on a same-day handoff visit that should have been Staying |
| **No Final Time Out** | Multiple same-day activities with no final clock-out |

Use **Show issues only** to focus on rows that need attention. From Intake, the yellow banner's **Fix** dialog corrects session hours and handoff problems.

<Tip>
  Catch bad times at the source: Intake blocks submit when Time In / Time Out do not match the selected session. Enrollment flags are mainly for older records or edge cases.
</Tip>

## ThoughtSpot analytics (Admin only)

Admins can open **ThoughtSpot Analytics** from Enrollment (`/admin/thoughtspot-analytics`) for district-level enrollment Liveboards. Data Leads do not have this link.
