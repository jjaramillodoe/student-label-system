## Capture from production

A Playwright script captures public pages (and optional authenticated admin pages):

```bash
# Public pages only (sign-in, student QR page)
NODE_PATH=./tmp-playwright/node_modules node scripts/capture-docs-screenshots.cjs

# Also capture cabinets, enrollment, duplicates, etc.
DOCS_SCREENSHOT_EMAIL='you@schools.nyc.gov' \
DOCS_SCREENSHOT_PASSWORD='***' \
NODE_PATH=./tmp-playwright/node_modules node scripts/capture-docs-screenshots.cjs
```

<Note>
  Archive box QR pages (`/archive/box/...`) must not mount the global Header auth redirect. That fix is in `AppHeaderWrapper` — deploy it, then re-run the script to capture `public-archive-box.png` and `archive-box-label.png`.
</Note>

## How to add a screenshot

<Steps>
  <Step title="Capture the screenshot">
    Open the live app, navigate to the screen, and capture at full width. Prefer demo or anonymized data.
  </Step>
  <Step title="Save the file">
    Save as `docs/images/screenshots/your-name.png`.
  </Step>
  <Step title="Update the MDX page">
    ```mdx
    <Frame caption="Short description of what the reader should notice">
      <img src="/images/screenshots/your-name.png" alt="Accessible description" />
    </Frame>
    ```
  </Step>
  <Step title="Preview and deploy">
    Run `npm run docs:dev`, verify locally, then push to GitHub for Mintlify to deploy.
  </Step>
</Steps>

## Mintlify Frame tips

From [Mintlify Frames](https://www.mintlify.com/docs/content/components/frames):

- Always wrap screenshots in `<Frame>` for consistent borders and captions
- Use `caption` for what the image shows; Markdown links are allowed in captions
- Use `hint` when you want a note *above* the frame
- Keep `alt` text specific (role + page + key UI elements)
