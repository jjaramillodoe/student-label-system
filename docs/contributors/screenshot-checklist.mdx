<Tip>
  On macOS: **Cmd+Shift+4** then Space to capture a window. Crop sensitive student data before publishing.
</Tip>

## How to swap a placeholder

<Steps>
  <Step title="Capture the screenshot">
    Open the live app, navigate to the screen, and capture at full width.
  </Step>
  <Step title="Save the file">
    Save as `docs/images/screenshots/intake-form.png` (or overwrite the matching `.svg` in `placeholders/`).
  </Step>
  <Step title="Update the MDX page">
    Change the `src` in the `<Frame>` on that page:

    ```mdx
    <Frame caption="Intake form with DOB and BE/ESL fields">
      <img src="/images/screenshots/intake-form.png" alt="Intake form" />
    </Frame>
    ```
  </Step>
  <Step title="Preview and deploy">
    Run `npm run docs:dev`, verify locally, then push to GitHub for Mintlify to deploy.
  </Step>
</Steps>
