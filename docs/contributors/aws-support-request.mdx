Use this when emailing **AWS Solutions Architects**, **AWS Support**, or your **DOE cloud team**. Attach or link [AWS deployment](/contributors/aws-deployment) and the repo file `docs/aws-deployment-architecture.md`.

## Subject line

```
Request: Architecture review & EC2 deployment guidance — Next.js app + MongoDB (District 79 Student Label System)
```

## Email body

Copy and fill in `[brackets]`:

```
Hello,

I'm reaching out for help planning a production deployment of our internal web application on Amazon EC2. We are moving off Vercel and need guidance on the right AWS setup — ideally using Docker and Docker Compose on a single EC2 instance to start, with room to scale later if needed.

Application summary
• Name: Student Label System (District 79 Adult Education)
• Type: Monolithic Next.js 16 application (Node.js 20) — UI and REST API in one process
• Database: MongoDB (database name: student-label) — currently on MongoDB Atlas
• Current production URL: https://student-label-system.vercel.app
• Repository: jjaramillodoe/student-label-system

What the app does
The system manages student records, physical file placement (cabinets/drawers/archive boxes), label printing, intake workflows, and admin reporting for adult education programs.

Key integration
Microsoft Power Automate calls our sync API nightly for Dynamics/Dataverse:
  GET /api/sync/v1/students
  Authorization: Bearer <SYNC_API_KEY>

What we need help with
1. EC2 instance sizing for low-to-moderate internal traffic (~4,400 records, ~10 users)
2. HTTPS — ALB + ACM vs Nginx on EC2
3. MongoDB Atlas (VPC peering) vs self-managed MongoDB on EC2/EBS
4. Security groups and secrets (Secrets Manager / SSM)
5. ALB health check configuration (GET /api/health)

What we've prepared
• Architecture document (attached): aws-deployment-architecture.md
• Dockerfile and docker-compose.yml in the repository
• Health endpoints for liveness/readiness monitoring

Proposed starting topology
Internet → ALB (HTTPS) → EC2 (Docker Compose) → Next.js :3000
                                              → MongoDB Atlas (or EC2 MongoDB)

Happy to schedule a call to walk through the architecture diagram.

Thank you,

[Your name]
[Title / Team]
[Email]
```
