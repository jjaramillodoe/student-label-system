## Cabinets page

**Admin → Cabinets** (`/admin/cabinets`) manages where student files live.

- Create cabinets with multiple drawers
- Drawer capacity presets: **100**, **200**, or **400** files
- Filter by school, capacity status, usage, and name
- **Smart Fill** creates standard cabinet structures quickly (default **400** per drawer)
- **Sync Counts** recalculates drawer counts and refreshes automatic **sections**

## Automatic sections

Each drawer is split into **8 sections** (about **1/8** of capacity) for physical filing:

| Drawer capacity | Approx. per section | Labels |
| --- | --- | --- |
| 400 | 50 | Section 01–08 |
| 200 | 25 | Section 01–08 |
| 100 | ~13 | Section 01–08 |

Sections are assigned **automatically** when a student is stored (intake, create, bulk upload, or move). They are **not** shown on the Intake form.

Data Leads see them:

- On cabinet cards (section occupancy grid under each drawer)
- On the Dashboard location column: **Cab** / **Draw** / **Sec**

<Tip>
  After upgrading, click **Sync Counts** once so existing files get Section 01–08 assigned by created order within each drawer.
</Tip>

## Cabinet Health

**Admin → Cabinet Health** shows full, near-full, empty, and over-capacity drawers. Archived students with a valid archive box are excluded from "missing cabinet" warnings.

## Unassigned queue

**Admin → Unassigned** lists students missing a valid cabinet or drawer assignment.

## Bulk move

**Admin → Bulk Move** moves selected students with capacity validation before saving. Moved students receive a new section in the target drawer.

## Archived files

Archived students live in **archive boxes**, not active drawers. When they return through Intake, staff see the box location and QR instead of a new drawer assignment — see [Intake → Returning archived students](/workflows/intake#returning-archived-students).
