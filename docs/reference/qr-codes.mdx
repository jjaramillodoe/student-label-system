## Student label QR

```
https://student-label-system.vercel.app/student/{labelId}
```

Public page shows Label ID, Student ID, name, DOB, cabinet, drawer, school, and sibling links.

## Archive box QR

```
https://student-label-system.vercel.app/archive/box/{boxId}
```

Public page shows box label, cabinet, school year, storage location, archive date, and the full student file list. Supports print and PDF download.

## Mintlify search MCP (this docs site)

After you deploy this documentation on Mintlify, your hosted MCP URL will be:

```
https://YOUR-SUBDOMAIN.mintlify.app/mcp
```

Replace `YOUR-SUBDOMAIN` with your Mintlify subdomain from the dashboard. Use that URL in Cursor so AI can search **your** documentation while you write or support staff.

For **district79**, use `https://district79.mintlify.app/mcp`.
