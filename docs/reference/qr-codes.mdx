## Student label QR

```
https://nycadultedlabels.nyc/student/{labelId}
```

Public page shows Label ID, Student ID, name, DOB, cabinet/drawer **or** archive box location, school, and sibling links.

## Archive box QR

```
https://nycadultedlabels.nyc/archive/box/{boxId}
```

Public page shows box label, cabinet, school year, storage location, archive date, and the full student file list. Supports print and PDF download.

Intake uses the same box URL (with QR) when staff log a visit for an **archived** returning student so they can find paperwork without a new drawer.
