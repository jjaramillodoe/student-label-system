## 1. Sign in

Go to [nycadultedlabels.nyc/auth/signin](https://nycadultedlabels.nyc/auth/signin) and sign in with your NYC DOE email and password, then your **MFA authenticator code**.

<Warning>
  **MFA is required for password sign-in** until DOE Single Sign-On is available. If you have not enrolled yet, you will be sent to **Profile** to set it up before using the rest of the app. See [User roles → Security](/user-roles#security-requirement--mfa-until-sso).
</Warning>

Your role determines which pages you can access:

| Role | Primary starting point |
| --- | --- |
| Intake Member | `/intake` (full-screen intake) |
| Data Member | Dashboard (`/`) with left sidebar |
| Data Lead | Dashboard + left sidebar tools |
| Admin | All schools + left sidebar (including Users, Security, Settings) |

After sign-in (except Intake Members), use the **left sidebar** to jump between Dashboard, Intake, Cabinets, Print Queue, and other tools. On mobile, open it from the **menu** button in the top bar. Press **⌘K** / **Ctrl+K** for the command palette.

See [User roles](/user-roles) for the full permission matrix.

## 2. Complete your first task

<Tabs>
  <Tab title="Intake Member">
    <Steps>
      <Step title="Open Intake">
        You land on `/intake` after sign-in.
      </Step>
      <Step title="Register or log a visit">
        - **NEW** — enter name, DOB (must be **21+** for BE/ESL), phones, address, employment / race / barriers, session, and times
        - **RETURNING** — search the student, then record today's visit only
      </Step>
      <Step title="Watch session hours">
        Time In / Time Out must fall inside the selected intake session window or submit is blocked.
      </Step>
      <Step title="Review the success summary">
        Confirm what was saved. Under-21 students get a copyable [P2G](https://p2g.nyc/contact/) referral message. Labels are printed later in batches from the Dashboard.
      </Step>
    </Steps>

    <Frame caption="Intake form used by front-desk staff">
      <img src="/images/screenshots/intake-form.png" alt="Student Intake form" />
    </Frame>
  </Tab>
  <Tab title="Data Member">
    <Steps>
      <Step title="Open the Dashboard">
        Search by name, Label ID, or Student ID.
      </Step>
      <Step title="Print labels">
        Optionally click **Needs label** to show only students who have never been printed. Select students → open print preview → **Download Word Doc** → print from Word on **Letter** at **100%** (Avery **5163** or **94205**) → confirm **Yes — mark as printed**. Labels show **Last, First**, DOB, a 5-digit batch sequence, barcode, and QR.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Data Lead">
    <Steps>
      <Step title="Review cabinet health">
        In the left sidebar open **Storage → Cabinet Health** and resolve unassigned students or full drawers. On **Cabinets**, use **Active** / **Archived** tabs; **Restore** brings a packed cabinet back. Drawers use sections **01–08** automatically — run **Sync Counts** on Cabinets after upgrades if sections are missing.
      </Step>
      <Step title="Bulk upload when needed">
        **Students → Bulk Upload** previews CSV rows, flags duplicates/date errors, and lets you remove bad rows before import.
      </Step>
      <Step title="Check enrollment issues">
        Open **Students → Enrollment** and filter to intake time issues when needed.
      </Step>
      <Step title="Verify addresses">
        Use **Students → All Students** to run NYC Geoclient verify on a page or batch.
      </Step>
    </Steps>

    <Frame caption="All Students — address verification and filters">

    </Frame>
  </Tab>
</Tabs>

## 3. Learn the ID system

Every student has two IDs:

- **Label ID** — short ID on the barcode and QR (e.g. `1979-JJ-0000001`)
- **Student ID** — ASISTS-aligned demographic ID (e.g. `JARAMILLOJAVIERR012251979`); legacy matches keep the full ASISTS export ID

Details: [Dual ID system](/reference/dual-id-system)
