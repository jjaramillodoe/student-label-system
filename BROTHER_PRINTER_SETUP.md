# Brother QL-800 Professional Label Printer Setup Guide

## Printer Specifications
- **Model**: Brother QL-800
- **Print Speed**: Up to 93 labels per minute
- **Resolution**: 300 DPI
- **Connectivity**: USB
- **Auto Cutter**: Yes (automatic label cutting)
- **Label Type**: Continuous feed (Brother DK pre-sized labels)

## Supported Label Types

The system is optimized for the following Brother DK label types:

1. **DK-1201** (1.1" x 3.5") - Recommended for student ID labels
2. **DK-11208** (1.1" x 2.1") - Compact labels
3. **DK-2205** (2.1" x 2.1") - Square labels
4. **DK-22208** (2.1" x 2.8") - Extended labels

## Browser Print Settings

### Chrome/Edge
1. Open Print dialog (Ctrl/Cmd + P)
2. Select "Brother QL-800" as printer
3. Click "More settings"
4. Set the following:
   - **Paper size**: Custom (match your label size, e.g., 3.5" x 1.1" for DK-1201)
   - **Margins**: None
   - **Scale**: 100%
   - **Background graphics**: ✓ Enabled
   - **Headers and footers**: Unchecked

### Firefox
1. Open Print dialog (Ctrl/Cmd + P)
2. Select "Brother QL-800" as printer
3. Click "More Settings"
4. Set the following:
   - **Paper size**: Custom (match your label size)
   - **Margins**: None
   - **Scale**: 100%
   - **Print Background Colors**: ✓ Enabled
   - **Print Background Images**: ✓ Enabled

### Safari
1. Open Print dialog (Cmd + P)
2. Select "Brother QL-800" as printer
3. Click "Show Details"
4. Set the following:
   - **Paper size**: Custom (match your label size)
   - **Scale**: 100%
   - **Print backgrounds**: ✓ Enabled

## System Configuration

### Label Template Selection
When printing, select the appropriate Brother DK label template:
- **Brother DK-1201** for 1.1" x 3.5" labels
- **Brother DK-11208** for 1.1" x 2.1" labels
- **Brother DK-2205** for 2.1" x 2.1" labels
- **Brother DK-22208** for 2.1" x 2.8" labels

### Print Workflow
1. Select students to print
2. Click "Print Selected" or "Print All Filtered"
3. Choose the appropriate Brother DK label template
4. Review the print preview
5. Click "Print"
6. Follow the print dialog instructions for Brother QL-800 settings
7. Confirm print settings match the label size

## Printer Driver Installation

1. Download Brother QL-800 drivers from [Brother Support](https://support.brother.com)
2. Install the driver for your operating system
3. Connect the printer via USB
4. Verify printer is recognized in system settings
5. Test print a sample label

## Troubleshooting

### Labels not printing correctly
- Verify label size matches template selection
- Check browser print settings (margins, scale, background graphics)
- Ensure printer driver is up to date
- Verify label roll is properly loaded in printer

### Barcodes not scanning
- Ensure barcode is not cut off at edges
- Check barcode size is appropriate for label
- Verify print quality is set to 300 DPI
- Test barcode with scanner before printing multiple labels

### Alignment issues
- Use the ruler in print preview to verify dimensions
- Adjust padding in custom label settings if needed
- Check printer's label alignment settings
- Verify label roll is properly aligned in printer

## Best Practices

1. **Always preview before printing** - Use the print preview to verify layout
2. **Test print first** - Print one label to verify alignment before batch printing
3. **Keep labels loaded** - Ensure label roll is properly loaded before printing
4. **Monitor label stock** - Use the Label Stock management page to track inventory
5. **Use correct template** - Match the template to your physical label size

## Scanner Integration

The system includes barcode scanner support for:
- Quick student lookup by scanning barcode
- Mobile-friendly scanner interface
- Manual entry fallback option

Ensure your barcode scanner is configured to work with the Brother QL-800 printed labels.
